# MeetingNote Pro 이슈 보고 항목

차후 보고할 때 그대로 쓰도록 모은 목록. `결정기록.md` 는 무엇을 정했는지, 이 문서는 **원본 자료와 구현이 어긋나는 곳과 아직 열린 위험** 을 보고용으로 정리한다. 작성일 2026-10-08, 대상 change `add-mvp-core`.

상태: **조치됨** = 구현에서 처리하기로 정함 / **보류** = 차후 논의 / **확인 필요** = 구현 전에 사실 확인 / **위험 수용** = 알고 안고 감

## B. 확정 디자인(`publish/`)이 디자인시스템 규칙을 어긴 곳 (구현에서는 규칙대로 고침)

| ID | 위반 | 위치 | 구현 처리 | 상태 |
|---|---|---|---|---|
| R-08 | 버튼 높이 44px 가 아님 (`h-10` · `h-9`) | `detail.html` 수정 · 삭제 · 취소, `todos.html` 담당자 필터 · 담당자 선택(`h-10` · `h-7`), `team.html` 이름 저장(`h-9`, `bg-blue-dot`) | 44px 하나, 이름 저장은 `btnPrimary` | 조치됨 (D-005) |
| R-09 | `window.UI` 이름 대신 클래스 문자열을 복붙, 인라인 `style` 사용 | `login.html` · `detail.html` · `team.html` · `meetings.html` 입력 · 버튼, `meetings.html` 진행 표시 `style="width:%"` | `UI` 이름만 사용, 필요한 이름은 `theme.js` 에 먼저 등록, 진행 표시는 `<progress>` | 조치됨 (D-005, D-022, D-023) |

보고할 말: 확정 디자인 HTML 이 디자인시스템 규칙(44px 하나, 이름만 사용, 인라인 style 금지)과 어긋난다. 구현은 규칙을 따르고 `publish/` 는 수정하지 않았다. 원본 `publish/` 를 규칙에 맞게 고칠지 정해야 한다.
